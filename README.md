# Silveira Software — Landing Page Oficial

Site oficial da **Silveira Software**: portfólio, stack, projetos e contato.

🔗 **Live:** [silveira-software.vercel.app](https://silveira-software.vercel.app)

## Stack

- **Next.js 16** (App Router) + React 19 + TypeScript
- **Tailwind CSS 4**
- **Framer Motion + GSAP + Lenis** — animações e smooth scroll
- **next/og** — Open Graph image gerada em runtime
- Deploy: **Vercel**

## Rodando local

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Estrutura

- `src/app/` — layout, página única e OG image (`opengraph-image.tsx`)
- `src/components/` — seções da página (Hero, About, TechStack, Projects, ClientSites, Contact, Footer) + navegação, cursor customizado
